Project Overview
This repository implements a reproducible, version-controlled, and continuously tested ML pipeline for IRIS flower classification, built across weekly assignments.

Week 2 - DVC Integration
Integrated Data Version Control (DVC) into the IRIS pipeline for reproducible, version-controlled data and model artifacts, backed by Google Cloud Storage.

Approach:
- Used DVC to version control the IRIS dataset and trained models
- Configured Google Cloud Storage as the DVC remote backend
- Created two versions of data and models to demonstrate versioning

Key files:
- train.py - training script for the IRIS classification model
- data/v1data.csv.dvc, data/v2data.csv.dvc - DVC pointers to dataset versions
- model.joblib.dvc - DVC pointer to the trained model artifact
- .dvc/config - DVC remote configuration pointing to the GCS bucket

GCS remote storage: gs://mlops-iris-csv-pipeline-unique/dvc-storage

Week 4 - CI/CD for the IRIS Pipeline
Added Continuous Integration using GitHub Actions, automatically validating the pipeline on every push and pull request.

What's included:
- test_model.py - pytest suite covering data validation and model evaluation tests
- metrics.csv, eval_data.csv - generated by train.py, used by the test suite
- .github/workflows/ci.yml - GitHub Actions workflow that authenticates to GCP using Workload Identity Federation, pulls data/model via DVC, runs tests, and posts a CML report as a comment

How to reproduce:
1. Clone this repository
2. Install dependencies: pip install dvc dvc-gs pandas scikit-learn joblib pytest
3. Pull data and model: dvc pull
4. Train the model: python train.py v1data.csv
5. Run tests locally: pytest test_model.py -v
